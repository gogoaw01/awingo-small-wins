AwinGo｜小成果俱樂部 V1.7｜GitHub Pages 上架說明

重要：本版 QR Code 固定指向：
https://gogoaw01.github.io/awingo-small-wins/club.html
因此請使用 GitHub 帳號 gogoaw01，建立公開儲存庫「awingo-small-wins」。
如果要使用其他帳號或儲存庫名稱，請先重新產生 assets/club-qr.png，改成新網址，否則 QR Code 會連錯地方。

上架步驟：
1. 登入 GitHub，New repository → 名稱 awingo-small-wins → Public → Create repository。
2. 選 Add file → Upload files。
3. 將本資料夾內的 index.html、club.html、assets 整個資料夾上傳（不要只傳 ZIP）。
4. Commit changes。
5. Settings → Pages → Build and deployment：Deploy from a branch → main → /(root) → Save。
6. 等 GitHub Pages 完成部署後開啟：
   https://gogoaw01.github.io/awingo-small-wins/
   https://gogoaw01.github.io/awingo-small-wins/club.html
7. 手機測試：首頁三入口、抽卡、填目標、計時、成果頁、下載 PNG、掃 QR、粉專私訊。

注意：目前無法代替你登入 GitHub 或確認倉庫是否存在；請先確認 GitHub 帳號是 gogoaw01。
本版不收集使用者資料，紀錄儲存在瀏覽器 localStorage。
